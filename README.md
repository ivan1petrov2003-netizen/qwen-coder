# ☁️ Облако — веб-приложение в стиле Windows 11

Облачное хранилище с проводником Windows 11: вкладки, «стеклянные» панели, фоновое видео,
регистрация/вход/гости, общая папка, публичные ссылки, приглашения по логину, корзина,
поиск, квоты и панель администратора.

## Требования

- **Node.js ≥ 22.5** — обязателен, так как БД реализована на встроенном модуле `node:sqlite`
  (в Node 20 его нет). Проверить версию: `node -v`.

## Как запустить

```bash
npm install        # ставит зависимости сервера и клиента (workspaces)
npm run dev        # запускает всё сразу (сервер + клиент)
```

После запуска откройте в браузере:

| Адрес | Что там |
|---|---|
| **http://localhost:5173** | Приложение (Vite dev-сервер, API проксируется на 3001) |
| http://localhost:3001 | Express API + раздача фонового видео |

### Продакшен-режим (один порт)

```bash
npm run build -w client   # собирает клиент в client/dist
npm start                 # Express отдаёт собранный клиент и API на :3001
```

Тогда достаточно одного адреса — http://localhost:3001

## Учётные записи

- **Администратор:** логин `user`, пароль `user123` (создаётся автоматически при первом запуске).
- **Гость:** любой посетитель автоматически получает анонимную сессию — можно работать без регистрации.
- Обычные пользователи регистрируются через кнопку «Регистрация» (логин + пароль).

## Структура

```
server/src/     index.js, config.js, db.js, auth.js, permissions.js, storage.js, routes/*
client/src/     App.tsx, store.tsx, api.ts, styles.css, components/*
data/           SQLite-БД и хранилище загруженных файлов (создаётся автоматически)
background.mp4  фоновое видео (в корне проекта, раздаётся по /background.mp4)
```

## Полезно знать

- Горячие клавиши: `Ctrl+N` — новая папка, `Delete` — удалить, `F2` — переименовать, `Ctrl+F` — поиск.
- Перетащите файлы в окно проводника — начнётся загрузка (drag & drop).
- Квота по умолчанию — 1 ГБ на пользователя; настройки внешнего вида сохраняются только у авторизованных.
